### [Market Behavior Lab](https://github.com/jcd1991/market-behavior-lab)

Archived quantitative research exploring how adaptive strategies respond to changing market regimes.

- Python strategies running on the Freqtrade runtime
- Regime detection, portfolio sizing, and risk controls
- Walk-forward and robustness-oriented validation
- Failed and venue-dependent results documented alongside successes

This is an experimental research artifact, not a profitability claim.

## How I work

- Make system behavior observable before automating it.
- Prefer deterministic evidence over generated explanations.
- Design dangerous operations with previews, limits, and approval gates.
- Treat failed experiments as useful engineering results.
- Keep credentials and sensitive data local whenever possible.
